# HALCON语义分割坐标偏移

## 现象

分割 mask 映射回原图后整体向右下偏移。

## 根本原因

前处理做了 letterbox，但后处理只按缩放比例还原，没有减去 padding。

## 最终修复

先恢复有效区域，再按原始比例逆变换。
