# 创建HALCON模板匹配工具方案

## 适用场景

在 C# 客户端中做通用模板编辑、训练、保存和匹配调用。

## 完整步骤

1. 封装 ROI 编辑。
2. 暴露模板训练接口。
3. 保存模板参数与版本。
4. 运行时返回匹配分数、角度、中心点。
5. 加入测试图回归验证。

## 风险

ROI 与训练样本不稳定会导致分数波动。
