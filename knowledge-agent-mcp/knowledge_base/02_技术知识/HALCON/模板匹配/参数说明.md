# HALCON模板匹配关键参数说明

`min_score` 决定最低匹配阈值，过高会漏检，过低会引入误检。

`greediness` 提升速度但可能降低复杂场景稳定性。

角度范围和金字塔层级应与实际姿态波动匹配。
