# HALCON模板匹配标准流程

## 标准流程

1. 选定稳定 ROI。
2. 预处理图像，降低噪声与光照影响。
3. 创建 `shape_model` 或 `scaled_shape_model`。
4. 在运行图中执行 `find_shape_model`。
5. 根据返回角度和分数做位姿判断。

## 关键点

模板必须覆盖稳定轮廓。ROI 过大通常降低速度，ROI 过小会降低鲁棒性。
