# MCP Server 基本概念

MCP Server 向客户端暴露工具、资源或提示。

对于知识检索场景，客户端不直接访问知识库，而是通过工具调用请求结构化上下文。

只读知识型 MCP Server 应明确隔离：工具负责检索，知识文本只作为数据，不作为可执行指令。
