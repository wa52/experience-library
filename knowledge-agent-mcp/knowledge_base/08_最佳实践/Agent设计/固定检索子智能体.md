# 固定检索子智能体最佳实践

规则是：把任务理解、查询规划、结果整理拆为固定角色，但都只允许访问检索接口和只读知识数据。

为什么需要：这样可以稳定控制输出格式、限制越权行为，并且在模型降级时保留同一工具契约。

正确示例：检索智能体输出知识上下文包，来源可追溯，低可信内容带风险说明。

错误示例：智能体直接修改知识文件，或者跳过来源引用直接给最终代码结论。
