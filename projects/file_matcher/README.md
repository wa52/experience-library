# 文件匹配工具

## 项目概述
高性能文件搜索与匹配工具，用于查找重复文件、批量文件归类、内容搜索。

## 技术栈
- Python — 核心逻辑
- threading / concurrent.futures — 多线程
- hashlib — 文件哈希
- watchdog — 文件监控（可选）

## 架构要点
- 生产者-消费者模式：扫描线程 + 工作线程池
- 队列缓冲避免内存溢出
- 支持按名称/大小/内容/MD5 匹配

## 关键经验
1. Queue + Lock 是线程安全的数据交换方式
2. HDD 场景并发数不宜过高（2-4 线程）
3. 超长路径用 pathlib 处理，避免 Windows MAX_PATH 限制
4. 大文件用分块读取 + 更新哈希，避免一次性加载内存

## 结果
- 已完成，性能满足 10 万级文件目录处理
