# ObjectDetectionModelTester — 项目总览

## 一句话

WPF + HALCON 24.11 的目标检测模型测试工具，用于加载 `.hdl` 检测模型、图片、标签映射和 HALCON region，验证目标检测结果、置信度、ROI 裁剪推理和 OK/NG 判定。

## 定位

面向工业视觉目标检测模型的离线测试和调参。核心价值是把 HALCON 深度学习检测模型的原始输出、过滤结果、CSV 结果和图像叠加框展示清楚，便于排查模型、阈值、ROI 和坐标映射问题。

## 技术栈

- C# / WPF / .NET 8 Windows
- HALCON 24.11 Progress Steady
- HDevelop 脚本由 C# 服务动态生成并执行
- CSV 结果输出 + WPF Canvas 叠加显示

## 核心功能

1. 选择 HALCON `.hdl` 目标检测模型。
2. 加载图片文件夹并逐张测试。
3. 从数据集读取标签，或手动配置 `id=label` 映射。
4. 可选加载一个或多个 HALCON region 文件作为测试 ROI。
5. 输出检测框、标签、置信度、原图坐标和 CSV。
6. 显示 HALCON 诊断日志，包含模型尺寸、原始检测数、ROI 裁剪区域和坐标缩放。

## 当前业务规则

- 检测到超过阈值的目标为 `OK`。
- 未检测到超过阈值的目标为 `NG`。
- 有 ROI 时只把 ROI 外接矩形裁剪区域送入模型，不做整图检测后屏蔽。

## 状态

已完成一次关键问题修复：HALCON 24.11 检测结果批次读取、低置信度输出排查、ROI 裁剪推理、坐标回映射和 OK/NG 判定方向。
