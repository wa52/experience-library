# FTS5 召回遗漏元数据导致咨询类别补齐失败

## 问题现象

引入 FTS5 后，普通关键词搜索正常，但部分咨询场景无法补齐 `code_example` 等类别。

## 根因

全文索引只包含标题、摘要和正文，没有包含技术、语言、版本等用于咨询召回的上下文。严格版本过滤无结果时，类别补齐也无法找到可参考案例。

## 解决方案

FTS5 索引同时写入领域、类别、知识类型以及结构化元数据；候选召回后继续使用现有元数据过滤和评分。仅在咨询类别补齐阶段，在严格版本无结果时允许保留技术和类别约束、放宽版本条件。

## 验证

通过全部 11 个 pytest 测试，包含 HALCON 模板匹配和语义分割坐标恢复验收场景。

## 教训

全文召回字段必须覆盖上层查询规划实际依赖的上下文，不能只根据正文搜索效果判断索引完整性。
